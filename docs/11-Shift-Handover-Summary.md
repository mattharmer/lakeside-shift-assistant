# THE LAKESIDE HOTEL · Document 11
## Shift Handover Summary

Version 1.0 | November 2026 · Internal use only

## 1. Purpose

A one-page handover from one shift to the next. It supports the end-of-night report in Document 01, section 15. It does not replace the incident registers or the cash-up sheet.

## 2. Rules

1. Use only what was pasted or told to you. Write **not provided** where information is missing.
2. Do not write passwords, safe codes or alarm codes.
3. Do not include guest personal details.
4. The Duty Manager checks and signs it.
5. If the pasted roster has a staff member marked "new", list them under "Who's new" and tell the Duty Manager they need a buddy (Document 05, section 3).

## 3. How to fill it in

1. Paste the roster export and your notes.
2. Fill the header and the roster table.
3. Compare the roster against the roles needed (bar, floor, kitchen, gaming if open). List any gap.
4. Add incidents and open items. Include register entry numbers if you have them.
5. Add equipment faults. For fixes, link to Document 04 (the section that applies).
6. Add stock run-outs and 86'd items.
7. Add bookings, functions and VIP notes.
8. Write 3 to 5 clear actions for the next shift.
