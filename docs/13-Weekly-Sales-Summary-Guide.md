# THE LAKESIDE HOTEL · Document 13
## Weekly Sales Summary Guide

Version 1.0 | November 2026 · Internal use only

## 1. Purpose

Turn one week of POS sales into a short summary the manager can act on. Sales figures are sensitive. Only the manager and owner see the finished summary.

## 2. The golden rule

**Use only numbers from the pasted export.** Do not estimate, round up, fill gaps, or use outside figures. If the data is missing or unclear, say so and ask the manager.

## 3. What to export each week

Export from the POS: [placeholder: report name and menu path, from the POS supplier or manager].

1. Set the date range: Monday to Sunday, or the week set by the manager: [placeholder].
2. Export **item sales by day and hour** as a **CSV**.
3. Export the **previous week** the same way, for comparison.
4. Check the columns. The summary needs at least:

| Column | Example heading |
|---|---|
| Date | [placeholder] |
| Hour | [placeholder] |
| Item name | [placeholder] |
| Category (for example cocktails) | [placeholder] |
| Quantity sold | [placeholder] |
| Sales value | [placeholder] |

5. ⚠️ If columns are missing or named differently, tell the manager before building the summary.
6. Do not paste guest names, card details or staff names. Remove them from the export first.
7. If POS or EFTPOS were down during the week (Document 04), note the dates. Some sales may be missing or entered later.

### 4.5 Three suggested actions
