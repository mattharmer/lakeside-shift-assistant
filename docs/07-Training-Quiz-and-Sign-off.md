# THE LAKESIDE HOTEL · Document 07
## Training Quiz and Sign-off

Version 1.0 | November 2026 · Internal use only

## 1. Purpose

Check that staff have read and understood Documents 01 to 06. Each document has 5 questions. Answers are in the "Answer" line, with the source section.

## 2. How it works

1. Read the document first.
2. Answer the 5 questions for that document, one at a time.
3. Pass mark is **80%**, which means **4 out of 5**.
4. Record the score on the sign-off table (section 9).
5. ⚠️ On a fail: re-read the sections you got wrong, then **retake with the Duty Manager (ext. 201)**.
6. The Duty Manager initials every pass.

If a question or answer here no longer matches the current document, the document wins. Tell the Duty Manager so this quiz can be fixed.
