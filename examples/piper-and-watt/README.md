# Piper & Watt — Trades Ops Assistant

A second, lighter Claude Project pack, using the same method as the Lakeside Shift Assistant in a different industry.

**Piper & Watt Plumbing & Electrical** is an invented Newcastle and Lake Macquarie trades business, not a real company. It exists to show that the approach is not tied to hospitality.

## What is in this folder

Custom instructions and four documents for office staff, tradespeople and apprentices:

1. Quoting guide and example price list (AUD incl. GST, clearly labelled as example rates)
2. Job safety checklist / pre-start (heights, isolation and lock-out, asbestos awareness, confined spaces; NSW WHS referenced only in general terms)
3. Customer FAQ and booking / after-hours policy
4. New apprentice induction

The boxed custom instructions tell the assistant to answer only from the documents, cite them, escalate safety-critical and electrical-compliance questions to the licensed supervisor, and never give do-it-yourself electrical advice to a customer.

Test questions, an Artifact prompt for a simple quote estimator, and a short 30–45 second demo script are at the end of [`docs/00-Custom-Instructions.md`](docs/00-Custom-Instructions.md). Question 5 is the one that should refuse and escalate.

This is a documents pack only. There is no separate app for this example.
